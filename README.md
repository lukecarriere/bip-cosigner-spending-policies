# Co-signer Spending Policies

BIP draft (v2, 5 Oct 2026) by Luke Carriere for a portable spending policy used by policy-enforcing Bitcoin co-signers.

The spec is in [bip-cosigner-spending-policies.md](bip-cosigner-spending-policies.md).

This standardizes the policy, not the co-signer. One format covers open, blinded, and enclave verification, and conditions from the transaction or from external oracles (DLC attestations required).

Status: Draft. Not yet assigned a BIP number.
